# WHITE AI — propostas para revisão

Os relatórios analisados pelo backend podem gerar arquivos Markdown nesta pasta,
cada um contendo o diagnóstico, a confiança, testes sugeridos e um diff unificado.

**IMPORTANTE:** o código sugerido não é aplicado nem executado. A comparação é
contra um SHA específico do arquivo; sempre confira se ele ainda corresponde à
versão atual antes de implementar qualquer correção.

O agente só pode gravar nesta pasta e apenas na branch experimental fixa.
Não altera `Inventory.lua`, `CombatFarm.lua` ou qualquer outro arquivo de
produção automaticamente.
